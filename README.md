# Portfolio — Japhet Bondoumbou

Portfolio personnel statique de Japhet Bondoumbou, étudiant en génie logiciel et développeur logiciel basé à Brazzaville (République du Congo).

Le site est entièrement statique, bilingue (français / anglais), avec un thème clair par défaut et un thème sombre optionnel. Il ne nécessite aucune installation npm, aucun backend et peut être hébergé gratuitement sur Vercel.
